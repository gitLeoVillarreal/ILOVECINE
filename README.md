# I LOVE CINE
#### Video Demo: https://youtu.be/i7fGSz6awIE
#### Description:
This is my CS50x Final Project: "I LOVE CINE"
It's a movie web app where you can get some recommendations from a movie that you liked or play a guessing game using the posters of random movies.

#### Requirements

- TMDB API key (https://www.themoviedb.org/)
- Python libraries (Flask, sqlite3, dotenv, json)

#### Structure
My web app it's designed with HTML and CSS and also has a backend with Python's library Flask. The project uses a python file called helpers.py where you generate a massive database in sqlite3 where you store the movies in a table called **movies** calling the TMDB API, you can manage how many movies you will save with a variable that stores the number of pages you want to loop, approx every page has like 20 movies, I used it with 100 pages that stores like 1600 movies depends on the filters you use. Also, I saved the genres in another table called **genres**, where I manage the names of them because the movies only have genres stored by IDs. All the requests are made on helpers.py so in app.py you manage the movies through the database.

#### Files
- `app.py`: Flask application with the three routes (/home, /recommend, /guess) and the logic that queries the database.
- `helpers.py`: Collects movie and genre data from the TMDB API and builds the SQLite database (movies and genres tables).
- `requirements.txt`: Python dependencies needed to run the project.
- `database.db`: SQLite database generated by helpers.py. Not included in the repository — run `MovieDataBase()` and `GenreDataBase()` from helpers.py to generate it locally.
- `.env` / `.flaskenv`: Environment variables, including the TMDB API key and Flask configuration (not committed to version control).
- `templates/layout.html`: Base template with the shared page structure and navigation.
- `templates/home.html`: Landing page with the video demo presentation card.
- `templates/recommend.html`: Form to input a movie title and displays the recommended movies table.
- `templates/guess.html`: Poster-guessing game interface with the blur effect and scoring logic.
- `static/styles.css`: Styling for all pages.
- `static/favicon.ico`, `static/favicon-16x16.png`, `static/favicon-512x512.png`: Site favicons.

##### helpers.py
Here is all the movie's info collection. In this file you will find two constant variables: **LEN** and **MAX_PAGE**. You can change it if you want to. Also, it will have many functions but only 2 are needed at ***main()**
**MovieDataBase()** and **GenreDataBase()** that creates the database that will be used by the app. Functions:
- `MovieList()`: This function returns a list with all the movie's info requested in a json format that will be used like a python dictionary to be sorted by popularity.
- `LookupPoster(poster)`: Check if there is a poster. If it's true, then return the poster_url to use as an image. If not, the function will return a "Not Found" string.
- `GenreList()`: This function returns a list with all the genre info requested in a json format that will be used like a python dictionary.
- `GenreDataBase()`: This function creates the table **genres** and calls the function **GenreList()**. It will insert every genre in the GenreList result via SQL query with the help of a loop.
- `MovieDataBase()`: This function creates the table **movies** and calls the function **MoviesList()**. It will insert every movie in the MovieList result via SQL query with the help of a loop. Every movie stores its genres as a comma-separated list of genre IDs, which is why the genres table is used to resolve them into names.

Also, I want to add the database schema that I used for the tables:

CREATE TABLE movies (
ID INTEGER PRIMARY KEY AUTOINCREMENT,
Movie_id INTEGER NOT NULL UNIQUE,
Title TEXT NOT NULL,
Poster_url TEXT NOT NULL,
Genre_ids TEXT NOT NULL,
Popularity NUMERIC NOT NULL,
Rating NUMERIC NOT NULL,
Release_date DATE NOT NULL
);


CREATE TABLE genres (
ID INTEGER PRIMARY KEY AUTOINCREMENT,
Genre_id INTEGER NOT NULL UNIQUE,
Name TEXT NOT NULL
);


##### app.py
Here you'll find 3 routes home or index, recommend and guess:
- /home: Here will be **home.html** it has my presentation card for the video demo. Feel free to ignore it.
- /recommend: This route will render **recommend.html** is a form inline with just one input and one button. The user will insert the title of a movie that they like, send it to app.py with the POST method in the button, then with the title provided by the user, they will call a function **recommend("movie_title")** that will search for the movie_id located in the **movies** table, and with the movie_id it will make a request to get the recommendations with the TMDB API those movies will be store in a dictionary to render the template again but with a table with the recommendations.
- /guess: This route renders **guess.html** This is a guess game with 5 tries. Every try, you lose 10,20,30,40 and 50 points. For every correct guess you get 100 points. The logic that modifies the poster uses the guesses, so every time you click the input, the script will check how many tries you have and change the blur effect.

#### How to use it
To use my app, you need to get an API key from TMDB. You only have to log <a href= "https://www.themoviedb.org/">here</a> in and select the developer usage for the API key, then go to helpers.py and run **MovieDataBase()** and **GenreDataBase()** that will create the database tables. Then do "Flask run" in your terminal and feel free to use it.
